## Changes

Plain HTML/HTM websites are now discovered alongside application dev scripts and use the same Start, Stop, Restart, Open, and log controls.

- Launch standalone sites without package.json or installing project dependencies, using a bundled static helper and installed Node.js.
- Group multiple pages under one managed loopback origin. Prefer an index page; otherwise show and open a deterministic entry page.
- Keep React, Vite, Next.js, and Node application detection ahead of HTML fallback, including incomplete/unsupported application setups and directly selected application public folders.
- Prevent duplicate/pending launches and overlapping static/application servers. Preserve active launch metadata through rescans and remove superseded inactive static entries.
- Retain discovery exclusions, canonical identity, the current pagination/inline details layout, and npm/Vite behavior.
- Migrate saved project metadata to schema v2 while preserving roots, theme, exclusions, recovery, and a separate legacy rollback backup.
- Serve ordinary web assets with GET/HEAD and block traversal, directory listing, hidden/private configuration files, and symlink paths.

## Compatibility and limits

- Windows local validation uses the existing Node.js 24+ and Electron installation. Static sites need no per-site npm dependencies; unsupported script package managers remain unsupported.
- Automatic static discovery conservatively skips generated and documentation/example/asset subtrees. Explicit standalone roots follow the documented ownership rules.
- Overlapping static roots cannot run concurrently; sibling website roots can use separate servers.
- No PHP/backend execution, automatic SPA fallback, live reload, public sharing, installer, or automatic project installs.
- External website assets/services retain their own network requirements. The one-server guarantee covers manager-owned launch registrations, not independently started processes or arbitrary child servers created by custom scripts.
- Older binaries cannot read schema v2. Manual rollback uses the preserved v1 backup, which does not include later v2 settings changes.
