## Provenance

The six fictional names are atlas-dashboard, beacon-api, canvas-studio, harbor-docs, orbit-storefront, and summit-starter. They are generated by [the capture script](../../scripts/capture-showcase.mjs) under an isolated fixture directory. The normal app catalog is not read, and existing user projects are not registered, launched, or shared.

These are real Electron renderer captures, not image-generation mockups. Discovery, IPC, Vite/Node/HTML server startup, owned endpoint readiness, and logs are real. The native picker response is stubbed. Three actual local fixture servers are running in the captures; the other three entries are stopped, and the pnpm entry correctly has execution unavailable.

For presentation, the script replaces only fixture path text and tooltips with `C:\Demo Projects` in the renderer before capture. Actual backend paths remain in the isolated temporary fixture. Names, counts, statuses, local ports/PIDs, and output are not invented. No personal project names or paths are visible. There is no active public preview link in these images.

The sharing confirmation is opened and then cancelled. No tunnel or new external preview is created. Normal quit is followed by checks that all three fixture URLs have closed; the fixtures and isolated user data are removed. [Capture metadata](../media/screenshots.json) records the result.

## Recreate

Use the manager's source folder on native Windows x64, with its dependencies and Electron runtime prepared:

```powershell
npm.cmd run setup:sharing
npm.cmd run build
node scripts/capture-showcase.mjs
```

Sharing setup prepares the optional binary so the confirmation control is available; it does not publish anything. Capture requires working Windows CIM/process cleanup. It overwrites only the four showcase images and metadata, creates its own temporary demo data, and never reads your normal catalog. No persistent mock project installation is needed.

Review regenerated images and captions before posting. Keep `.test-artifacts/`, normal user data, logs, and raw local inspection reports out of publication assets.
