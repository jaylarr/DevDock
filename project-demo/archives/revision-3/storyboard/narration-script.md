# Narrated showcase — marketing revision 3

The story starts with a recognizable developer problem, then shows six actual actions and results. A conversational American English synthetic narrator, precisely timed sentence captions, a quiet original rhythmic track, closer camera moves and quicker cuts replace long silent dashboard holds. Target: 50 seconds, 1080p, 30 FPS.

| Time | Speech and visual action |
| --- | --- |
| 00–04 | “Still juggling terminals? Meet Local Dev Manager.” Three illustrated terminal cards resolve into the product identity. |
| 04–11 | “Add one folder. Your Vite, Node, and static projects appear together.” Real folder discovery. |
| 11–19 | “Pick a project. Hit Start. Watch it become a verified, running server.” Focus moves to the actual Start control, then returns to the result. |
| 19–26 | “Need answers? Open live logs, the local address, and runtime details.” Logs expand and scroll into view; close focus makes them legible. |
| 26–32 | “Search by name. Or filter to just the servers running now.” Natural typing, one matching project, then three active servers. |
| 32–39 | “Sharing starts with a clear access check. Here, we're only reviewing the confirmation.” Actual access/compatibility dialog; no tunnel. |
| 39–46 | “Switch to dark mode. Three local servers, all in one workspace.” Real theme switch and running fixtures. |
| 46–50 | “Less terminal juggling. More building.” Product name and confirmed technology stack. |

`narration.json` is the editable script. Captions start and end with the generated audio for each spoken sentence; long lines wrap into two lines. The audio pipeline measures actual clip lengths, adjusts a scene's speech gently if required, adds natural sentence pauses and exports both SRT and timestamped JSON. No estimated word-level karaoke timing is claimed.

The illustrated terminals are an opening motion graphic, not fabricated recording evidence. All feature footage remains the real Electron app with fictional local projects. Scene headlines use clean cuts rather than crossfading two different labels. Subtitles live in a dedicated bottom area outside the application. The original procedural music is quiet and ducked under narration.

Revision 3 keeps this spoken script and timing, while adding floating perspective cards, kinetic typography, animated orbit/grid lighting, chapter icons, short benefit transitions and a stronger closing identity. Original synthesized motion sounds follow those transitions. See `storyboard.md` for the visual choreography.
