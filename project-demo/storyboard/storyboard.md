## Capture evidence

All feature footage comes from real Electron in dedicated user data with fictional generated projects. Actual IPC, discovery, Windows process ownership, HTTP readiness, logs, search/filter and theme actions are retained. npm and HTML preview screenshots come from their actual verified local servers in isolated Chromium. OS browser launching is intercepted during recording; no ordinary user tabs or catalog are read. The native picker is stubbed.

Paths are redacted. Hover styling, pointer and ripples are capture-only editorial effects. Terminal illustrations, framing, chapter icons and animated headlines are editorial graphics. Startup waits are condensed and labeled. Sharing opens and cancels the real access/compatibility confirmation; no public tunnel is started and its footage is labeled accordingly. Normal quit cleanup is verified.
